# מיפוי מסגרות לגיל הרך (0–3) — היתכנות וכלי נתונים

> **Social Finance Israel (SFI) | Data & Measurement**
> פרויקט לבחינת היתכנות פיתוח כלי אוטומטי למיפוי מסגרות חינוך לגיל הרך בישראל

---

## רקע

לא קיים בישראל מיפוי לאומי מלא של מסגרות החינוך לגיל הרך (גילאי 0–3). הפרויקט נועד לבדוק האם ניתן לבנות כלי שיאסוף, יעבד וינגיש את הנתונים הללו — תחילה ברשות מקומית אחת (פיילוט), ולאחר מכן ברמה ארצית.

**המצב הידוע (מתוך דו"ח מרכז המחקר של הכנסת, מרץ 2023):**
- ~550,000 פעוטות בגילאי 0–3 בישראל; כ-60% שוהים במסגרת כלשהי
- ~2,240 מעונות יום מוכרים עם סמל (משרד החינוך)
- ~3,600 משפחתונים מוכרים
- ~2,181 מעונות פרטיים ללא סמל
- ~1,000 מעונות פרטיים שמעולם לא הגישו בקשת רישוי (מופיעים רק בנתוני ביטוח לאומי)

**הקשר רגולטורי:** בינואר 2022 הועבר הפיקוח ממשרד הכלכלה למשרד החינוך; כ-225 ממוני גיל הרך מונו ברשויות עד מרץ 2023. תיאור תפקיד של מנהל/ת יחידת גיל הרך (ינואר 2025) כולל במפורש את מיפוי המסגרות כאחריות ליבה.

## ארכיטקטורת המערכת המוצעת

המערכת מורכבת משני מסלולי עבודה:

### מסלול 1: כלי איסוף נתונים ומיפוי
מערכת היברידית לאיסוף ועדכון נתונים על מסגרות גיל הרך ברשויות מקומיות.

```
מקורות נתונים
├── רשמיים: משרד החינוך, זרוע העבודה, משרד השוויון, נתוני הרשות
└── קהילתיים: קבוצות Facebook, אתרי המלצות

        ↓

פייפליין עיבוד (Python)
├── איסוף אוטומטי (API / Scraping)
├── זיהוי כפילויות (שם + כתובת)
├── מנגנון לידים לממתין לאימות
└── אימות ידני ע"י ממונת גיל הרך

        ↓

מסד נתונים מרכזי
└── דשבורד ניהולי (Power BI / Web)
```

### מסלול 2: ממשק מלווה לתהליך ייעוץ
ממשק ווב המחליף את מחברת ה-PowerPoint — מאפשר ניהול מחברות דיגיטליות לצוותי ייעוץ ולרשויות, ללא צורך בניהול קבצי Drive.

## אתגרים מרכזיים שזוהו

- **כפילויות:** מסגרות המוזנות ממספר מקורות (פתרון: התאמת שם+כתובת + מזהה ייחודי)
- **שינויי שם:** מסגרות שמשנות שם לאחר אירועים (אלגוריתם Fuzzy Matching)
- **מסגרות שנסגרו:** אין מנגנון דיווח סגירה אוטומטי — נדרש זיהוי פרואקטיבי
- **גישה למקורות:** חלק מהמקורות הרשמיים דורשים בקשה ספציפית ולא API פתוח
- **רגולציה:** בחינת מגבלות רכש של השלטון המקומי והיבטי AI Policy
