# MVP — דאטה סט מסגרות לידה-3 ברשות

שלב 1 בלבד: בניית דאטה סט מתוקף מכמה מקורות. בלי ממשק ובלי הנגשה.

## הרצה

```bash
pip3 install -r mvp/requirements.txt
set -a && source .env && set +a      # GOOGLE_API_KEY
python3 -m mvp.evaluate               # שליפה + איחוד + השוואה למיפוי הידני (קרית אתא, נתניה)
python3 -m mvp.validation_task --city נתניה   # קובץ תיקוף ידני
python3 -m mvp.dictionary             # ייצוא מילון הנתונים לאקסל
```

הפלטים נשמרים ב-`data/output/`. התיקייה `data/` מוחרגת מ-git כי יש בה שמות וטלפונים.
שליפות גולמיות נשמרות ב-`data/raw/<תאריך>/`, כך שהרצה חוזרת באותו יום לא פונה שוב למקורות.

## קבצים

| קובץ | מה עושה |
|---|---|
| `config.py` | ערי הפיילוט, שנות לימוד, נתיבים |
| `sources.py` | שליפה מ-6 מקורות: משרד החינוך, זרוע העבודה, משרד הבריאות, משרד הרווחה, בדרך לגן, Google Places |
| `normalize.py` | ניקוי שמות וכתובות |
| `build.py` | איחוד ישויות (סמל → כתובת+שם → טלפון+שם), סמל פיקטיבי, טבלת מסגרות |
| `evaluate.py` | השוואה למיפוי הידני של הרשות (קרקע אמת) |
| `validation_task.py` | קובץ עבודה לתיקוף ידני |
| `dictionary.py` | מילון הנתונים: שדות, מקורות, שאלות פתוחות |

## הוספת רשות

מוסיפים רשומה ל-`CITIES` ב-`config.py` (שם, קוד ישוב למ"ס, מרכז, slug של "בדרך לגן").
אם יש מיפוי ידני — מוסיפים פונקציית קרקע אמת ב-`evaluate.py`.
